### 🎤 Speaker Notes

> "This is where things get interesting. Let me walk you through the pipeline."
>
> "Every 33 milliseconds — one frame — the webcam delivers a 1280×720 BGR image. That frame is preprocessed: resized, normalized, letterboxed for each model's expected input. Then it fans out to three concurrent inference sessions."
>
> "Each session runs on the Hexagon Tensor Processor — the HTP inside the Snapdragon X Elite. This is a purpose-built AI accelerator, separate from the CPU and the Adreno GPU. It is not running AI on the graphics card. It is not running AI on the CPU cores. It's running on dedicated neural processing hardware."
>
> "All three models are loaded simultaneously using the QNN Execution Provider in ONNX Runtime. The Hexagon HTP supports model pipelining — it can schedule multiple QNN graphs across its independent DSP cores without evicting weights between frames. That means YOLOv8 is running at the same time as MiDaS, at the same time as hand tracking. True hardware parallelism."
>
> "For the smaller models — YOLOv8n at roughly 6 megabytes — we pin weights to the on-chip VTCM cache. That's 8 megabytes of ultra-fast vector memory directly on the Hexagon chip. Once those weights are pinned, we eliminate DDR memory bandwidth as a bottleneck entirely. That's where we get the 8 millisecond YOLO inference — not from a faster model, from smarter memory management."
>
> "We use FP16 precision on the HTP. Qualcomm's AI Hub provides pre-quantized variants of all three models. FP16 gives us exactly double the throughput of FP32 with no meaningful accuracy degradation for object detection, depth estimation, or hand tracking workloads."
>
> "The outputs — bounding boxes, a dense depth map, and 21 3D hand landmarks — are fused in a lightweight CPU layer that computes 3D world positions for each detected object. Those 3D positions initialize PyBullet rigid bodies, which simulate zero-gravity physics at 60 hertz."
>
> "End result: 28 milliseconds from raw pixel to rendered AR frame. 31 frames per second. CPU sitting at 12 percent. Total system power draw under 8 watts."
>

>
> "That's the Snapdragon X Elite doing what it was built for."
>
